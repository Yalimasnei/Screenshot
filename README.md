# Screenshot

独立的 Windows 托盘截图工具，使用 C++17 和 Win32 开发。支持矩形、窗口、全屏、任意形状截图、文字识别、取色和截图标注。HDR 桌面转换为 SDR 后保存。

本仓库提供程序源码、构建脚本、资源和说明。当前版本为 **1.0.0**。

## 目录结构

```text
Screenshot/
├── src/
│   ├── app/         # 入口、设置和应用状态
│   ├── capture/     # 桌面捕获、像素转换和 HDR 映射
│   ├── core/        # 公共类型和图像操作
│   ├── encoding/    # 图片输出、HEIC 和 NVENC
│   ├── platform/    # Windows 路径和文字识别
│   └── ui/          # 选框、编辑器、设置和通知
├── resources/       # 版本信息和管理员清单
├── third_party/     # 保留原许可的外部头文件
├── scripts/         # build.ps1、export-source.ps1
├── docs/            # 第三方说明
├── LICENSE
└── README.md
```

构建后产生的 `bin/` 和 `build/` 不纳入源码仓库。源码文件采用小写下划线命名；外部头文件保留上游名称。

## 构建

需要 Windows、PowerShell 7 和 x86-64 llvm-mingw 工具链，确保同一工具链的 `clang++.exe` 和 `llvm-windres.exe` 在 `PATH` 中。所需头文件和链接库由 llvm-mingw 提供。

```powershell
pwsh -File .\scripts\build.ps1
```

输出为 `bin\Screenshot.exe`。目前在 Windows 11 x64 上验证，其他 Windows 版本未完成实机验证。程序通过系统接口使用 Windows HEIF 编解码器、OCR 和 NVIDIA 驱动，不附带这些运行时组件。PNG 截图不依赖 NVIDIA 显卡或 HEIF 编码器。

## 使用

运行 `bin\Screenshot.exe`，程序显示托盘图标。手动启动要求管理员权限；这能处理管理员权限游戏处于前台时的截图快捷键。首次运行或手动启动时，Windows 可能显示 UAC 确认。

- **PrtScn** 或 **Win+Shift+S**：打开截图栏。
- 矩形：拖动框选；窗口：单击高亮窗口；全屏：截取整个桌面；任意形状：拖出轮廓，松开闭合。
- 文字识别：框选文字或单击窗口，使用已安装的 Windows OCR 语言包。
- 取色器：单击复制 `#RRGGBB` 颜色。
- **Esc** 或右键：取消截图。
- 单击截图通知打开编辑器，支持笔、荧光笔、橡皮擦、裁剪、撤销和重做。
- 编辑器支持 **Ctrl+C** 复制、**Ctrl+S** 另存为、**Ctrl+Z / Ctrl+Y** 撤销和重做。裁剪时 **Enter** 应用，**Esc** 取消。

截图同时提供剪贴板 PNG 和 CF_DIB 位图。任意形状的轮廓外在 PNG 中透明，在位图中铺白。编辑停顿后会自动复制；较早的编辑复制或文字识别结果不会覆盖之后的新操作。退出程序会先询问是否保存编辑器中的修改，取消后继续运行。

设置在托盘菜单中打开，改动即时保存。可调整自动保存、文件夹、格式、NVENC 色度采样、通知、快捷键、主题、语言、开机启动和选区尺寸提示。关闭成功通知后，无法通过通知打开编辑器；错误提示仍会出现。

- 语言默认跟随系统界面语言，可选中文和 English。
- 主题可选跟随系统、浅色或深色。
- “显示选区尺寸”默认关闭，控制矩形、窗口和文字模式的“宽 × 高”提示。
- 默认自动保存到系统“屏幕截图”文件夹，可指定其他位置。
- 配置是 exe 同目录的 `Screenshot.ini`（UTF-8 BOM），日志为 `%TEMP%\Screenshot.log`。
- 开机启动使用当前用户的最高权限登录计划任务。新任务名包含用户 SID；已有属于当前用户的旧任务会继续使用。关闭此设置会删除当前用户的对应任务。移动程序后应重新确认任务指向的位置。
- 运行期间可屏蔽 Windows 截图快捷键，退出后解除。Xbox Game Bar 的快捷键不保证能拦截。

## 保存格式与精度

| 设置 | 编码及位深 | 色度采样 | 透明截图 |
| --- | --- | --- | --- |
| PNG | 8 位 RGB 通道，无损压缩 | 不适用 | 支持 |
| NVENC | NVIDIA HEVC 编码，使用保留的像素选择 8 / 10 位 | 可选 4:2:0 / 4:4:4 | 主图与透明辅助图使用 8 位 4:2:0 |
| HEIC | Windows HEVC 编码，8 位，最高质量 | 4:2:0 | 通过系统辅助帧接口保存 |

NVENC 采用 HEVC 无损模式，但 RGB 与 Y′CbCr 转换、量化和色度抽样仍可能损失信息，不能把结果视为 PNG 的逐像素无损替代。Windows HEIC 是有损编码，最高质量也不等于无损。4:4:4 通常保留更多彩色文字和边缘细节，但文件可能大于 PNG。

捕获按当前输出位深和实际捕获格式保留高精度像素。编辑器按最终保存格式合成：NVENC 保留相应精度，PNG、Windows HEIC、JPEG 和剪贴板沿用每通道 8 位路径。复制或保存 8 位图片不会清除可编辑底图中的高精度数据。

仅在设备通过所需的 HEVC 编码能力检测后开放 NVENC；4:4:4 也按当前位深所需的设备能力开放。不支持的设备在设置中禁用 NVENC，另存为列表也不提供该选项。

读取旧设置或处理不同精度的输入时，NVENC 请求的位深、采样或输入格式不可用则尝试 8 位 4:2:0；编码仍不可用、尺寸受限或解码校验失败时，自动保存回退 PNG。Windows HEIC 不可用或校验失败时同样回退 PNG。编辑器另存为 HEIC 失败会提示选择其他格式。

HEIC 的奇数宽高会补一行或一列重复的边缘像素，以避免已观察到的系统解码缩放问题。保存前检查解码颜色与透明度；检查门槛只用于识别异常输出，不代表误差或跨查看器兼容性保证。

HDR 转换以对应显示器的 SDR 白为参考，再压缩高光；文件是 SDR，未保存原始 HDR。与屏幕物理观感可能仍有亮度差异。

## 源码导出

```powershell
pwsh -File .\scripts\export-source.ps1
```

脚本按明确清单生成 `build/packages/Screenshot-source.zip`，并重新读取压缩内容核对 SHA-256。也可用 `-OutputZip` 指定一个尚不存在的目标文件。Git 使用同样范围的文件白名单；本地配置、构建输出、历史和研究资料不进入仓库。不要直接压缩整个开发目录用于公开。

## 限制

不捕获鼠标指针，不提供录屏或延时截图。受保护内容可能为黑屏。OCR 取决于已安装的语言和文字大小。多屏、旋转、多显卡、不同 HEIC 查看器及实际登录自启仍需更多实机验证。动画目标跟随显示刷新率，但测试结果不保证所有设备上稳定达到该帧率。
